# Konstantin Prusakov — портфолио

Статический сайт: HTML, изображения, видео, аудио и локальные шрифты.

Для локального запуска из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory konstantin-portfolio
```

Открыть http://127.0.0.1:8000/.

Изменения в ветке `main` автоматически публикуются через GitHub Actions в GitHub Pages. Публикуется папка `konstantin-portfolio`.

Шрифты Onest, Oswald и Caveat находятся в папке `fonts` вместе с лицензиями SIL Open Font License.
